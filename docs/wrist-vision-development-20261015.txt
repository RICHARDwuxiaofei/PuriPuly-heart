4. P0/P1 实现边界
旧 native/overlay/、core/overlay/、app/services/overlay/ 相对基线零源码差异。
Bridge v15、旧字幕的排序/过期/重试及 OSC 路由未改。新窗口是单独进程和 OpenVR 句柄。
新功能默认关闭；本开发版需手动“应用/启动”，不因保存的偏好自动截图或上传。
SELF/PEER 从既有投递权限验证后的事件扇出，按话轮 ID 去重/更新，不重复 STT/文本翻译。
支持左右手、位置/尺寸/透明度、历史翻页、原文/译文模式及状态，关闭不退出主程序。
控制器当前采用 OpenVR legacy state + 另一只手的几何射线；不是完整 SteamVR actions
绑定方案。不同控制器/输入焦点的兼容性是必须优先进行的实机验收项。

截图只在另一只手扳机确认后执行；进取景状态时要求先释放，防止同一次按压误确认。
支持手腕框和头部跟随框；取消、取景超时、设备跟踪丢失会撤销待处理结果。
读取 SteamVR compositor 的左眼 D3D11 镜像，不读取 Windows 桌面。
有显式资源释放、场景 PID/Tracking Origin/位姿变化检查和越界/退化选区拒绝。
元数据包含头部/眼部位姿、投影切线范围、世界四角、图像四角/尺寸、PID、Origin、时间。
镜像帧没有可靠同步时间戳，当前是 best_effort_pose_guarded；不能保证任意动态场景完全
消除滞后。保留镜像直到下一次获取的处理参考 VRCS/OpenVR #1888。
新取景框在读回前隐藏；实际 VR 图像是否完全不含旧字幕，仍需头显场景确认。

视觉使用独立服务，官方端点 https://api.deepseek.com/chat/completions，默认 deepseek-flash。
协议依据：https://api-docs.deepseek.com/zh-cn/guides/vision/ （2026-10-15 核对）。
复用同一应用配置中的 DeepSeek BYOK 安全存储，不往普通文本管线塞图片。
目标语言留空时取当前有效语言；明确识别 401/403/429、服务不可用、超时、拒绝、
空内容、非 JSON、截断/过大响应。无自动付费重试。
选定截图仅存内存，完成/取消后释放，不记录图片、Base64、密钥或原始服务响应。
每次确认最多一个请求，重复事件与迟到结果被代次规则丢弃。
